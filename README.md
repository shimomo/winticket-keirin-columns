# WINTICKET Keirin Columns

ウィンチケット**競輪**の出走表で、列の並び替えと表示/非表示を設定できる Chrome 拡張機能です。オートレースは対象外です。

**非公式の個人開発です。** WINTICKET（株式会社WinTicket）とは無関係です。利用規約は各自でご確認ください。

出走表の「メモ」列は一番右にあるため、PC では横スクロールで隠れがちです。この拡張機能は、表示済みの表の列を手元のブラウザ内で並べ替えるだけで、WINTICKET への追加リクエストは送りません。設定は `chrome.storage.local` にだけ保存され、外部には送信されません。

## 使い方

1. このリポジトリを clone（または ZIP で展開）します。
2. Chrome で `chrome://extensions` を開き、右上の「デベロッパー モード」をオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」でこのフォルダを選びます。
4. 出走表を開くと、表の上に「列を設定」ボタンが出ます。

設定パネルでは、列をドラッグ（または ▲▼）で並び替え、チェックを外して非表示にできます。初期状態では「メモ」が選手名の隣に移ります。

## 仕様と制限

- 対象は PC 版 Chrome の `https://www.winticket.jp/keirin/*`（競輪）の、基本情報タブの出走表だけです。オートレースの出走表にはメモ列がないため、対象外です。EXデータ・直近成績・対戦成績などの表には何もしません。
- 枠・車・選手名の3列は、左の固定表と重なって表示されるため動かせません。
- 列は見出しの文字で特定します。サイトの見出しが変わると設定が外れることがあります。
- アイコンは自作です（`tools/make_icons.py` で再生成できます）。ウィンチケットのロゴや配色は使っていません。
- ビルド不要です。`manifest.json`、`content.js`、`content.css` だけで動きます。
